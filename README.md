\# Lowcode Project



\## About

This is a simple Flask web application created as part of my low-code, no-code and AI-assisted development course.



The application displays a greeting message on a web page.



\## Requirements

\- Python

\- Flask 3.1.2



\## Installation

1\. Create a virtual environment:

&#x20;  `python -m venv .venv`



2\. Activate the virtual environment on Windows Command Prompt:

&#x20;  `.venv\\Scripts\\activate`



3\. Install the required packages:

&#x20;  `python -m pip install -r requirements.txt`



\## Run the application

Run this command:



`python app.py`



Open http://127.0.0.1:5000 in your web browser.



\## Purpose

This project is my first step towards learning how to build and test web applications using Python, Flask and AI-assisted development.
